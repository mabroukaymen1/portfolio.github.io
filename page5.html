IoT Smart Home Automation System

A cutting-edge IoT solution integrating Flutter, ESP32, Firebase, and MQTT to deliver seamless home automation for enhanced safety, comfort, and efficiency.

What is the IoT Smart Home System?

This project is a comprehensive smart home automation system that allows users to monitor and control their home environment in real-time using a Flutter-based mobile app. Powered by ESP32 microcontrollers, it integrates sensors for temperature, humidity, fire detection, and energy monitoring. The system uses Firebase for cloud storage and MQTT for efficient communication, ensuring a responsive and secure user experience.

Key Features

  • Real-time monitoring of temperature, humidity, and power consumption.
  • Instant fire hazard detection with alerts.
  • Remote control of devices like lights and alarms.
  • User-friendly Flutter app with authentication and notifications.
  • Local display of sensor data via LCD.

Technical Overview

A detailed look at the system's architecture and implementation, highlighting the integration of hardware and software components.

System Architecture

  • ESP32: Collects sensor data and controls devices over Wi-Fi.
  • Firebase: Stores and syncs data in real-time.
  • Flutter App: Provides a user-friendly interface for control and monitoring.
  • MQTT: Ensures low-latency communication between devices and app.

Hardware Components

  • ESP32: Core microcontroller.
  • DHT11: Temperature and humidity sensor.
  • Flame Sensor: Fire detection.
  • ACS712: Current sensor for energy monitoring.
  • LED: Simulates smart lighting.
  • Buzzer: Audible alerts.
  • 16x2 I2C LCD: Local data display.

Software Components

  • ESP32 Firmware: Manages hardware and Firebase integration.
  • Firebase: Real-time data storage.
  • Flutter App: Cross-platform user interface.
  • MQTT Client: Efficient device communication.
