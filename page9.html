Core Innovations

Technical Features

Discover the advanced techniques that power this state-of-the-art Tunisian Arabic to English translation system.

Memory Optimization

Techniques to ensure efficient training on limited GPU resources:

  • Gradient checkpointing reduces memory usage by ~30%
  • Mixed-precision training (FP16/FP32) for speed and efficiency
  • 8-bit quantization for low-memory deployment
  • Dynamic batch size adjustment based on memory

Dialect-Specific Processing

Custom solutions for Tunisian Arabic dialect challenges:

  • Extended vocabulary with SentencePiece tokenization
  • Special tokens for code-switching (e.g., [AR], [EN])
  • Subword regularization for morphological variations
  • Robust handling of dialectal expressions

Advanced Training

Enhanced training methods for better model performance:

  • Curriculum learning with progressive difficulty
  • Noise injection for translation robustness
  • Data augmentation with synthetic code-switching
  • Early stopping with patience mechanism

Real-Time Monitoring

Tools for tracking and analyzing training progress:

  • Interactive dashboard with live metrics
  • TensorBoard integration for visualization
  • GPU memory usage profiling
  • Attention heatmap generation

Enhanced Architecture

Custom enhancements to the mBART-50 base model:

  • Multi-head attention with position bias
  • Learned attention temperature scaling
  • Relative position embeddings for context
  • Efficient attention mechanisms

Flexible Deployment

Options for deploying the model in production:

  • FastAPI endpoint for real-time serving
  • ONNX export for optimized inference
  • Docker containerization support
  • Interactive console for testing

  • Extended vocabulary with dialectal terms (e.g., "شكون", "زيد")
  • Special tokens for code-switching (e.g., [AR], [EN])

Get Started

Installation Guide

Step-by-step instructions to set up and run the Tunisian to English AI Translator on your system.

1

Prerequisites

  • NVIDIA GPU with CUDA 11.7+ (recommended, 8GB+ memory)
  • Python 3.8+ installed
  • Git for cloning the repository
2

Setup

# Clone the repository
git clone https://github.com/mabroukaymen1/tunisian_english.git
cd tunisian-translate-ai-model

# Create and activate virtual environment
python -m venv venv
# Linux/Mac
source venv/bin/activate
# Windows
venv\Scripts\activate

# Install dependencies
pip install torch==2.0.1+cu117 --extra-index-url https://download.pytorch.org/whl/cu117
pip install -r requirements.txt

# Optional: Install 8-bit quantization support
pip install bitsandbytes accelerate

# Prepare directories
mkdir -p models cache logs plots processed
3

Run the Pipeline

# Process the dataset (e.g., augmented_dataset.csv)
python process.py

# Start training the model
python train.py

Note: Ensure the dataset (e.g., augmented_dataset.csv) is placed in the data/raw/ directory before running process.py.
