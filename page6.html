LoRa-based Environmental Monitoring System

Project Overview

The LoRaMétéo Smart project, developed at Institut Supérieur d'Informatique de Mahdia under Dr. Zouhour Radaoui, leverages LoRa technology for efficient environmental monitoring. Using Heltec LoRa32 V3 modules and a DHT11 sensor, it transmits temperature and humidity data over 300 meters with a 2% packet loss rate and 0.5 mA power consumption during transmission. Data is displayed on an OLED and uploaded to Firebase for remote access.

System Architecture

How It Works

The complete workflow from sensor data collection to cloud synchronization

1

Sensor Data Collection

DHT11 sensor measures temperature and humidity values with ±2°C and ±5% accuracy respectively.

2

LoRa Transmission

Data is encoded and transmitted via LoRa at 868MHz frequency with 125kHz bandwidth.

3

Signal Reception

Receiver module captures the LoRa signal with RSSI values typically between -80dBm to -120dBm.

4

Local Display

Received data is displayed on the 128x64 pixel OLED screen with real-time updates.

5

Cloud Synchronization

Data is uploaded to Firebase via Wi-Fi for remote monitoring and historical analysis.
