LoRa-based Environmental Monitoring System

A low-power, long-range IoT solution for temperature and humidity monitoring

Project Overview

The LoRaMétéo Smart project, developed at Institut Supérieur d'Informatique de Mahdia under Dr. Zouhour Radaoui, leverages LoRa technology for efficient environmental monitoring. Using Heltec LoRa32 V3 modules and a DHT11 sensor, it transmits temperature and humidity data over 300 meters with a 2% packet loss rate and 0.5 mA power consumption during transmission. Data is displayed on an OLED and uploaded to Firebase for remote access.

Technologies Used

Heltec LoRa32 V3 DHT11 LoRa Protocol Arduino IDE DHT.h heltec-unofficial.h Firebase OLED Display

System Workflow

How the LoRa system collects and processes data

System Architecture

The system comprises two nodes:

  • Transmitter: Collects temperature and humidity data using a DHT11 sensor and sends it via LoRa.
  • Receiver: Receives LoRa data, displays it on an OLED, and uploads it to Firebase via Wi-Fi.

Workflow

  1. Sensor Reading: DHT11 measures temperature and humidity.
  2. LoRa Transmission: Data is sent wirelessly using LoRa protocol.
  3. Data Reception: Receiver parses incoming LoRa messages.
  4. Display: OLED shows real-time data and signal quality.
  5. Cloud Sync: Data is uploaded to Firebase for remote monitoring.

Performance Metrics

Key outcomes of the system

Results

The system enables reliable long-range data transmission with real-time visualization on an OLED display and cloud storage via Firebase, ensuring robust environmental monitoring.

Metrics

- Packet Loss: 2%
- Range: 300m (urban)
- Power Consumption: 0.5 mA (transmission)

Applications of LoRa

Real-world use cases

Why LoRa?

LoRa offers long-range, low-power communication, ideal for IoT applications requiring extended coverage and minimal energy use.

Applications

- Smart Agriculture: Soil moisture and weather monitoring.
- Smart Cities: Lighting and parking management.
- Logistics: Asset tracking and fleet management.
- Environmental Monitoring: Air quality, water levels, and fire detection.
