Aquatech Industrial Control System

A Flutter-based IoT solution for automated bottle filling and capping with real-time monitoring, developed at Institut Supérieur d'Informatique de Mahdia.

Smart Bottle Filling & Capping

Aquatech is an innovative IoT-based industrial control system designed for automated bottle filling and capping. As a key contributor to the project team, I developed the Flutter-based mobile and web app and integrated IoT functionalities to connect the app with hardware via Firebase and ESP32. Conceived by Louay Mdimagh, the project owner and originator, Aquatech enables remote monitoring, real-time analytics, and precise control of production parameters, enhancing efficiency in industrial automation.

System Architecture

How Aquatech Works

A sophisticated workflow combining mobile control, cloud processing, and hardware execution for seamless industrial automation.

1

Mobile Control

Users configure production parameters via the Flutter mobile app, which sends commands to Firebase in real-time.

2

Cloud Processing

Firebase acts as the central hub, processing commands and storing production data for real-time analytics.

3

Hardware Execution

ESP32 microcontroller retrieves commands from Firebase to control the filling and capping hardware.

4

Feedback Loop

Sensors send real-time feedback to ESP32, updating Firebase which syncs with the mobile app for monitoring.

Technology Stack

Components & Materials

Aquatech combines cutting-edge hardware and software for a complete industrial automation solution.

ESP32

Microcontroller that controls hardware and communicates with Firebase via Wi-Fi.

Solenoid Valves

Manages precise liquid flow for accurate bottle filling.

Stepper Motor

Powers the automated capping mechanism with precision.

Limit Switches

Detects bottle position and process status at each station.

Flutter App

Cross-platform interface for monitoring and control.

Firebase

Real-time database for data synchronization and commands.
