Aquatech - Smart Industrial Control System

A Flutter-based IoT solution for automated bottle filling and capping with real-time monitoring

Introduction

Aquatech is an innovative IoT-based industrial control system designed for automated bottle filling and capping, developed at the Institut Supérieur d'Informatique de Mahdia during the 2024-2025 academic year. As a key contributor to the project team, I developed the Flutter-based mobile and web app and integrated IoT functionalities to connect the app with hardware via Firebase and ESP32. Conceived by Louay Mdimagh, the project owner and originator, Aquatech enables remote monitoring, real-time analytics, and precise control of production parameters, enhancing efficiency in industrial automation.

System Architecture

Hardware and software components and their interactions

Materials Used

  • ESP32 Microcontroller: Controls hardware and communicates with Firebase via Wi-Fi.
  • Solenoid Valves: Manages precise liquid flow for bottle filling.
  • Stepper Motor & Driver: Powers automated bottle capping.
  • Limit Switches & Sensors: Detects bottle position and process status.
  • Relay Modules: Safely switches high-power devices.
  • Power Supply: Ensures stable voltage for all components.
  • Flutter App (Mobile/Web): User interface for monitoring and control.
  • Firebase: Real-time database for data synchronization and commands.

System Workflow

Bottle Filling & Capping
  1. User configures parameters via the Flutter App.
  2. Commands are sent to Firebase in real-time.
  3. ESP32 retrieves commands from Firebase to control hardware.
  4. Sensors send feedback to ESP32, updating Firebase.
  5. The app displays real-time data, alerts, and enables remote control.

Limitations & Future Improvements

Challenges and opportunities for enhancement

Current Limitations

  • Wi-Fi Dependency: Requires stable Wi-Fi for real-time control.
  • Scalability: Limited to small-scale production lines.
  • Power Consumption: High power usage for continuous operation.
  • Sensor Accuracy: Potential errors in low-quality sensors.

Future Enhancements

  • Edge Computing: Implement local processing to reduce Wi-Fi dependency.
  • Scalable Design: Support larger production lines with modular hardware.
  • Energy Efficiency: Optimize power usage with low-power components.
  • Advanced Sensors: Integrate high-precision sensors for improved accuracy.
