Bluetooth-Controlled Line Follower Robot

An innovative Arduino-based robot combining autonomous line following with Bluetooth-controlled navigation

Introduction

The Bluetooth-Controlled Line Follower Robot is a versatile robotics project developed at the Institut Supérieur d'Informatique de Mahdia during the 2024-2025 academic year. This Arduino-based robot autonomously follows a black line using infrared (IR) sensors while also offering manual control via a Bluetooth mobile app. Equipped with obstacle detection and avoidance capabilities, it showcases a blend of embedded programming, sensor integration, and wireless communication, making it ideal for applications like automated transport and robotic competitions.

How It Works

Technical Details and System Architecture

System Overview

The robot is powered by an ESP32 microcontroller, which processes inputs from three IR sensors for line detection, an ultrasonic sensor for obstacle detection, and a Bluetooth HC-05 module for manual control. It uses an L298N H-Bridge to control four DC motors, enabling smooth navigation. A servo motor aids in scanning for obstacles, enhancing autonomy.

Key Components

  • ESP32: Manages all logic, sensor data, and communication.
  • IR Sensors (3x): Detect the black line for autonomous navigation.
  • Ultrasonic Sensor + Servo: Scans and avoids obstacles.
  • L298N H-Bridge: Controls motor speed and direction.
  • HC-05 Bluetooth: Enables manual control via a mobile app.

Modes of Operation

  • Line Following: Uses IR sensors to track a black line and adjust motor speeds.
  • Obstacle Avoidance: Scans for obstacles and navigates around them.
  • Manual Mode: Controlled via Bluetooth commands (forward, backward, turn, stop).
  • Combined Mode: Integrates line following and obstacle avoidance.

Technologies Used

Arduino C/C++ ESP32 HC-05 Bluetooth IR Sensors L298N H-Bridge Ultrasonic Sensor Servo Motor

Limitations & Future Improvements

Challenges and Opportunities for Enhancement

Current Limitations

  • Lighting Sensitivity: IR sensors struggle in varying light conditions.
  • Complex Paths: Limited ability to follow intricate or sharp-turning lines.
  • Terrain Constraints: Performance drops on uneven surfaces.
  • Bluetooth Range: Limited to ~10 meters due to HC-05 constraints.

Future Enhancements

  • Advanced Sensors: Add LiDAR or additional ultrasonic sensors for better obstacle detection.
  • Improved Algorithms: Implement machine learning for adaptive line tracking.
  • Wi-Fi Connectivity: Replace Bluetooth with Wi-Fi for extended range.
  • Full Autonomy: Enable environment mapping for independent navigation.
