Embedded Systems Project

Bluetooth-Controlled Line Follower Robot

An innovative Arduino-based robot combining autonomous line following with Bluetooth-controlled navigation. Developed at Institut Supérieur d'Informatique de Mahdia during the 2024-2025 academic year.

View Demo View Code
Project Overview

Innovative Robotics Solution

This Arduino-based robot autonomously follows a black line using infrared (IR) sensors while also offering manual control via a Bluetooth mobile app. Equipped with obstacle detection and avoidance capabilities, it showcases a blend of embedded programming, sensor integration, and wireless communication.

Project Highlights

The Bluetooth-Controlled Line Follower Robot is a versatile robotics project that demonstrates practical applications of embedded systems. It can switch between autonomous line following and manual Bluetooth control modes, making it ideal for educational purposes and real-world applications like automated transport systems.

Arduino C/C++ ESP32 Bluetooth IR Sensors L298N
