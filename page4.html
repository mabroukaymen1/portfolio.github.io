Project Overview

Revolutionizing Office Productivity

Beemo represents a breakthrough in AI-powered office automation, designed and developed during my final-year project at Institut Superieur d'Informatique de Mahdia. This innovative assistant combines cutting-edge voice recognition with emotional intelligence to create a truly interactive workplace companion.

Intelligent Voice Recognition

Advanced speech-to-text processing using LinTO ASR Arabic Tunisia v0.1 model, supporting Tunisian Arabic with code-switching capabilities for French and English.

  • Tunisian Arabic dialect recognition with 95% accuracy
  • Seamless code-switching between Arabic, French and English
  • Local processing ensures complete data privacy
  • Noise cancellation for office environments
  • Custom vocabulary for technical terms

Emotional Intelligence

Unique emotional feedback system using OLED display and servo motors to create an engaging, human-like interaction experience that improves user satisfaction.

  • 12 distinct emotional states displayed on OLED
  • Physical head movements via servo motors
  • Context-aware reactions to user tone
  • Learning system that adapts to user preferences
  • Positive reinforcement for completed tasks

Mobile Integration

Flutter-based mobile application for seamless remote control, monitoring, and real-time interaction with your Beemo assistant from anywhere.

  • Cross-platform compatibility (iOS/Android)
  • Real-time task monitoring dashboard
  • Custom command creation interface
  • Voice command history and analytics
  • Remote troubleshooting capabilities

System Architecture

How Beemo Works

A sophisticated workflow combining voice processing, AI interpretation, and hardware execution for seamless office automation.

1

Voice Capture

High-quality microphone captures voice commands in Tunisian Arabic, French, or English with advanced noise filtering.

2

Speech Recognition

LinTO ASR Arabic Tunisia v0.1 model processes audio locally, converting speech to text with high accuracy for dialectal variations.

3

Intent Analysis

Advanced NLP algorithms running on Raspberry Pi analyze the transcribed text to understand user intentions and extract actionable commands.

4

Task Execution

Intelligent task manager executes commands through hardware controls or mobile app notifications based on the interpreted intent.

5

Feedback Response

OLED display shows emotional reactions while servo motors provide physical feedback, creating an engaging user experience.
